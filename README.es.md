## De la investigación al código

Si trabajas con clustering, aquí tienes por dónde empezar:

| Proyecto | Para qué puedes usarlo | Tecnologías |
| :--- | :--- | :--- |
| [**Chi-Index**](https://github.com/josemarialuna/Chi-Index) | Evaluar un clustering frente a etiquetas de referencia con un índice basado en chi-cuadrado. | Python |
| [**ClusterIndices**](https://github.com/josemarialuna/ClusterIndices) | Evaluar clusters a escala con BD-Silhouette, BD-Dunn, Davies–Bouldin y WSSSE. | Scala · Spark |
| [**ExternalValidity**](https://github.com/josemarialuna/ExternalValidity) | Comparar clusters con etiquetas de referencia mediante medidas de validación externa en Spark. | Scala · Spark |
| [**RandomClustersGenerator**](https://github.com/josemarialuna/RandomClustersGenerator) | Generar datos sintéticos agrupados para experimentar con algoritmos de clustering. | Python |

**Mis herramientas:** Python · Scala · Apache Spark · aprendizaje automático · análisis de datos

## Las preguntas que me mueven

- **¿Son buenos estos clusters?** Medidas de validación y métodos escalables para entender cómo se agrupan los datos.
- **¿Qué viene después?** Predicción de series temporales y aprendizaje con datos en streaming, especialmente en sistemas energéticos.
- **¿Podemos hacer más con menos?** Selección de características y aprendizaje automático eficiente en el uso de recursos.
- **¿Dónde puede ser útil?** Aplicaciones que van del consumo eléctrico y los hogares inteligentes a los datos biomédicos.
