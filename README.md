# Hi, I'm José María 👋

I research machine learning, teach computer science, and turn research ideas into code you can explore.

I'm an **Associate Professor (Profesor Titular de Universidad)** in the Department of Computer Languages and Systems at the **University of Seville**, and a member of the [Minerva research group](https://grupo.us.es/minerva/). My work connects **clustering, Big Data and time series forecasting**, with applications in energy, health and beyond.

What I enjoy most is the whole journey: asking a useful question, digging into the data, building something, and sharing what we learn along the way.

## From research to code

If you're working with clustering, these are a good place to start:

| Project | What you can do with it | Built with |
| :--- | :--- | :--- |
| [**Chi-Index**](https://github.com/josemarialuna/Chi-Index) | Evaluate clustering against reference labels using a chi-squared-based validity index. | Python |
| [**ClusterIndices**](https://github.com/josemarialuna/ClusterIndices) | Evaluate clusters at scale with BD-Silhouette, BD-Dunn, Davies–Bouldin and WSSSE. | Scala · Spark |
| [**ExternalValidity**](https://github.com/josemarialuna/ExternalValidity) | Compare clusters with reference labels using external validity measures in Spark. | Scala · Spark |
| [**RandomClustersGenerator**](https://github.com/josemarialuna/RandomClustersGenerator) | Generate synthetic clustered datasets to experiment with clustering algorithms. | Python |

**My toolkit:** Python · Scala · Apache Spark · machine learning · data analysis

## Questions I work on

- **How good are these clusters?** Validation measures and scalable methods for understanding how data groups together.
- **What comes next?** Forecasting time series and learning from streaming data, especially in energy systems.
- **Can we do more with less?** Feature selection and resource-efficient machine learning.
- **Where can it help?** Applications ranging from electricity consumption and smart homes to biomedical data.
